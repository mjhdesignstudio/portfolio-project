Featured Projects from my portfolio

Staff Family Tree Mural

This mural was commissioned by a local non-profit wanting a staff family tree. The project design was based on a wall decal design.

I was able to add specific elements requested by the client including bringing the tree roots all the way to the floor and arranging the tree branches in a heart-like shape.

Materials used: Acrylic paint, muliple sized brushes, and procreate for the initial design drawings.

React Weather App

This weather app provides real-time weather conditions and a 5 day forecast based on a default location (Gresham, OR), or a location based on a search query.

This app was built using React and the SheCodes Weather API in Visual Studio Code.

Baby Shower Invitation

This custom baby shower invitation was designed for a friend's baby shower. Due to pandemic restrictions at the time, we had to improvise and have a "drive through" baby shower. The simplicity of the design was inspired by my friend's style and the modern vercel workshop I had recently attended.

This invitation was created on cold pressed watercolor paper using a broad edge nib and gouache paint. The invitation was scanned and digitally sent.
